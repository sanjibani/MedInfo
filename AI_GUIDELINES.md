# Strict UI/UX Guidelines

## 1. Spacing System (Absolute Rule)
- **Multiples of 4px ONLY**: 4, 8, 12, 16, 24, 32, 48, 64.
- **NEVER** use arbitrary numbers like 3px, 5px, 17px, etc.
- **NEVER** use inline styles for spacing (allow Tailwind classes only).

## 2. Breathing Room
- **Generous Default**: Always err on the side of too much whitespace rather than too little.
- **Container Padding**: Minimum **24px (p-6)** for all main containers and cards.
- **Element Separation**: Distinct elements must clearly be separated.

## 3. Consistency
- **Standard Scale**: Use standard Tailwind classes (p-4, m-8, gap-4).
- **No Magic Numbers**: Avoid calculating arbitrary pixel values.

## 4. Typography
- **Scalable**: Use standard text sizes (text-sm, text-base, text-lg).
- **Readable**: Ensure high contrast and sufficient line height.
